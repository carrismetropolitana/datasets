## Divisões Administrativas - Distritos (CAOP 2023)

**Descrição**: Dados vetoriais dos distritos de Portugal com base na CAOP 2023.

**Fonte**: Direção-Geral do Território (DGT)<br>
**Responsável** pela Manutenção: Direção-Geral do Território (DGT)<br>
**Data** de Atualização: 2023<br>
**Formato**: SHP, GeoJSON<br>
**Área de Cobertura**: Lisboa, Setúbal e Évora<br>
**Projeção/CRS**: EPSG:4326 (WGS 84)<br>
**Propósito**: Cruzamento de divisões administrativas distritais com as posições das paragens da Carris Metropolitana.

**Observações**: Dados sujeitos a atualizações futuras conforme modificações administrativas.

## Divisões Administrativas - Localização de Lugares - Base Geral da Rede de Informação (BGRI) 2011

**Descrição**: Este conjunto de dados vetoriais representa as localidades de Portugal com base na BGRI de 2011, incluindo geometria e identificadores únicos.<br>
**Fonte**: Instituto Nacional de Estatística (INE) / Direção-Geral do Território (DGT)<br>
**Responsável pela Manutenção**: Instituto Nacional de Estatística (INE)<br>
**Data de Referência**: 2011<br>
**Formato**: SHP, GeoJSON<br>
**Área de Cobertura**: Cascais; Lisboa; Oeiras; Sintra; Amadora; Loures; Mafra; Vila Franca de Xira; Odivelas; Alenquer; Arruda dos Vinhos; Sobral de Monte Agraço; Torres Vedras; Almada; Seixal; Sesimbra; Alcochete; <br>Barreiro; Moita; Montijo; Palmela; Setúbal; Vendas Novas.
**Projeção/CRS**: EPSG:4326 (WGS 84)<br>
**Propósito**: Cruzamento de divisões administrativas das localidades com as posições das paragens da Carris Metropolitana.<br>

**Observações**: São utilizados os dados dos Censos 2011, uma vez que os de 2021 ainda se encontram incompletos.
